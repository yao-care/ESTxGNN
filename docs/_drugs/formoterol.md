## Formoterol: malformación respiratoria (respiratory malformation)
{: .text-alpha }

## Resumen en Una Frase

Formoterol es un agonista beta2-adrenérgico de acción prolongada que relaja el músculo liso de las vías respiratorias y se utiliza en enfermedades obstructivas del pulmón.
El modelo TxGNN predice que podría ser efectivo para **malformación respiratoria (respiratory malformation)**, pero actualmente hay **0 ensayos clínicos** y **ninguna publicación que estudie directamente esta enfermedad**, por lo que la predicción se apoya solo en el modelo.

## ¿Por qué es Razonable esta Predicción?

Actualmente no se dispone de datos detallados sobre el mecanismo de acción en los datos compilados para este informe. Según la información conocida, formoterol es un agonista beta2 de acción prolongada que relaja el músculo liso bronquial, y se administra por vía inhalatoria.

Este mecanismo actúa sobre el tono de las vías respiratorias, pero no puede corregir malformaciones estructurales congénitas del tracto respiratorio. No se identifica un vínculo mecanístico creíble con esta nueva indicación.

El puntaje alto del modelo probablemente refleja la cercanía con enfermedades respiratorias frecuentes como el asma o la EPOC, y no una relación terapéutica real. Por ello, el puntaje por sí solo no es suficiente para justificar avanzar.
